Pickflow 1.1.0 (1010012) · QA 빌드 · 운영 서버 (release)

직전 QA 빌드(1010011)에서 바뀐 것만 적었습니다.
이번 빌드는 개발 서버가 아니라 운영 서버를 보는 release 빌드입니다.

━━ 운영 서버 주소 이전 ━━

· 운영 API 주소가 api.pickflow-api.us 로 바뀌었습니다.
  지도·리스트·스팟 상세·보관함·마이페이지가 평소처럼 뜨는지 봐 주세요.

━━ 공유 링크 ━━

· 스팟 상세에서 공유하면 링크가 https://api.pickflow-api.us/... 로 나갑니다.
· 새 링크와 기존 링크(https://pickflow-api.us/...) 모두 탭하면
  앱의 스팟 상세로 바로 열립니다.

━━ 알려진 사항 ━━

· 운영 서버 빌드라 실제 서비스 데이터입니다. 스팟 등록·신고·탈퇴는
  실제로 반영되니 주의해 주세요.
· 개발 서버 계정과 데이터가 달라 로그인이 풀려 있으면 다시 로그인해 주세요.
· release 빌드라 개발자 메뉴(Dev Mode)가 없습니다.
· 기존 QA 빌드 위에 그대로 업데이트됩니다. 스토어 버전이 깔린 기기는
  삭제 후 설치해야 합니다.
