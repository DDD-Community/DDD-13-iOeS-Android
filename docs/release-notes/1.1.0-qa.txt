━━ [PV-79] 새 기능 안내 노출 ━━

새 기능 안내를 앱 업데이트 없이 Firebase Remote Config
(new_feature_flags)로 켜고 끌 수 있게 했습니다. 안내는 세 군데입니다.

· 탐색 탭 전체화면 팝업(V2 업데이트 안내) — 기기당 1회
· 무드 필터 "햇살"·"야경" 칩의 주황 점 — 노출 후 N일간
· 보관함 > 나만의 스팟 바텀시트(스팟 공개 안내) — 계정당 1회

━━ [PV-41] 내 스팟 오픈 ━━

· 내가 등록한 스팟을 "오픈 신청"해 모두에게 공개할 수 있습니다.
  등록 → 신청 → 검수중 → 승인/반려 흐름이 처음 들어갔습니다.
· 반려되면 상세에 사유 배너가 뜨고, "수정 후 재신청"을 누르면
  기존 입력값이 채워진 등록 화면에서 바로 다시 신청할 수 있습니다.
· 검수 결과는 홈 스낵바와 저장 탭 인디케이터로 알려드리고,
  승인 후 상세에 처음 들어가면 완료 모달이 한 번 뜹니다.
· 공개된 스팟은 지도·탐색 목록에 모두에게 보이고,
  나만보기 스팟은 작성자에게만 보입니다. 토글 상태는 유지됩니다.
· 공개 스팟에 추천을 누를 수 있습니다. 비로그인 시 로그인 안내가 뜹니다.

━━ [PV-107] 온보딩 ━━

· 이미지·문구가 모두 바뀌었고 전환 애니메이션은 제거했습니다.

  온보딩이 중복으로 뜨지 않습니다.
