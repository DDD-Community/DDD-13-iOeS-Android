Pickflow 1.1.0 (1010011) · QA 빌드 · 개발 서버

직전 QA 빌드(1010010)에서 바뀐 것만 적었습니다.
이번 빌드도 QA 제보 수정입니다.

━━ [PV-148] 반려 배너 오픈 철회 ━━

· 반려 배너의 "스팟 오픈 철회"를 눌러도 배너만 사라지고 실제로는
  철회되지 않던 문제를 고쳤습니다. 화면을 다시 열면 배너가 그대로
  돌아와 있었습니다.
· 이제 검수중 철회와 같은 확인 시트가 뜨고, 철회하면
  "오픈 신청을 철회했어요." 토스트와 함께 배너가 사라집니다.

━━ [PV-148] 보관함 공개 상태 표시 ━━

· 나만의 스팟: 공개 승인된 스팟의 노출을 꺼도 "공개" 배지가
  그대로 붙던 문제를 고쳤습니다. 이제 "비공개"로 표시됩니다.
· 저장된 스팟: 등록한 유저가 노출을 끈 스팟이 정상 셀로 보이고,
  누르면 상세가 열리지 않던 문제를 고쳤습니다.
  이제 "등록한 유저가 비공개로 전환하였어요" 셀로 보입니다.
· 위 비공개 안내 문구를 썸네일 가운데에서 아래쪽으로 옮겼습니다.

━━ [PV-148] 보관함 탭 갱신 ━━

· "저장된 스팟"·"나만의 스팟" 탭을 오갈 때마다 목록을 새로 읽습니다.
  다른 유저가 스팟을 비공개로 돌리거나 삭제한 결과가 탭만 바꿔도
  반영됩니다.
· 이미 목록이 떠 있으면 로딩 표시 없이 갱신돼 화면이 깜빡이지 않습니다.

━━ [PV-146] 탐색 리스트 하단 ━━

· 리스트를 끝까지 내리면 마지막 줄의 스팟 이름·북마크 버튼이
  지도/리스트 전환 버튼과 스팟 등록 버튼에 가려지던 문제를 고쳤습니다.

━━ 알려진 사항 ━━

· 개발 서버 빌드라 운영 앱과 데이터가 다릅니다.
· 개발자 메뉴(Dev Mode: 환경 배지 탭 → 패스코드 1123)
