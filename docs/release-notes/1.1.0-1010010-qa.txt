Pickflow 1.1.0 (1010010) · QA 빌드 · 개발 서버

직전 QA 빌드(1010009)에서 바뀐 것만 적었습니다.
이번 빌드는 QA 제보 수정이 대부분입니다.

━━ [PV-144] 저장 탭 북마크 버튼 ━━

· 북마크 아이콘을 눌러도 저장이 풀리지 않고 상세로만 들어가던 문제를
  고쳤습니다.
· 반대로 썸네일 우상단의 무드·거리 배지를 누르면 조용히 북마크가
  해제되던 것도 함께 고쳤습니다.
· 셀에 추천 수를 표기합니다.

━━ [PV-143] 스팟 상세 추천 ━━

· 추천을 누르면 헤더의 "추천 N" 이 바로 올라갑니다.
  그동안은 눌러도 숫자가 그대로였습니다.
· 추천 실패 안내 문구를 "잠시 후 다시 시도해주세요." 로 통일했습니다.
· 추천 성공·실패 토스트에는 체크 아이콘을 빼고 문구만 띄웁니다.
  등록 완료·제보 접수 등 기존 토스트의 아이콘은 그대로입니다.

━━ [PV-142] 보관함 갱신 ━━

· 스팟을 삭제하고 보관함으로 돌아오면 "나만의 스팟" 목록에
  삭제한 스팟이 그대로 남아 있던 문제를 고쳤습니다.
  이제 보관함에 다시 들어올 때마다 목록을 새로 읽습니다.

━━ [PV-137] 온보딩 ━━

· 화면이 짧은 기기에서 하단 버튼이 납작하게 눌리던 문제를 고쳤습니다.
  화면 높이 760dp 아래부터 눌렸고, 640dp 기기에서는 12dp 까지
  찌그러졌습니다.

━━ [PV-123] 지도 마커 ━━

· 내 스팟 마커가 다른 스팟과 묶여 숫자 뭉치로 들어가던 문제를
  고쳤습니다. 내 스팟은 항상 단일 마커로 보입니다.
· 내 스팟 마커에도 등록한 사진이 깔립니다.

━━ 알려진 사항 ━━

· 개발 서버 빌드라 운영 앱과 데이터가 다릅니다.
· 개발자 메뉴(Dev Mode: 환경 배지 탭 → 패스코드 1123)
