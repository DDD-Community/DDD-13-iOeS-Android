Pickflow 1.1.0 (1010009) · QA 빌드 · 개발 서버

직전 QA 빌드(1010008)에서 바뀐 것만 적었습니다.

━━ [PV-86] 탐색 리스트 정렬 필터 ━━

· 정렬 필터를 무드 필터 아래로 내렸습니다.
· 스크롤할 때 무드 행만 상단에 고정되고 정렬 행은 같이 올라갑니다.

━━ [PV-65] 지역 ━━

· 기본 지역과 목록 노출 순서를 대전에서 서울로 바꿨습니다.

━━ [PV-107] 온보딩 ━━

· 일러스트를 교체하고 2x/3x/4x 밀도 이미지를 넣었습니다.
  고해상도 기기에서 흐릿하게 보이던 부분이 개선됩니다.

━━ [PV-41] 스팟 공개 토글 ━━

· 공개/나만보기 상태를 기기에 저장하지 않고 서버 응답으로 판단하게
  바꿨습니다. 다른 기기에서 바꾼 상태도 그대로 따라옵니다.

━━ 서버 연동 교체 ━━

· 약관/정책과 버전 정책을 iOS용 임시 API 에서 안드로이드 API 로
  바꿨습니다. 강제 업데이트 판정도 이제 서버 값을 그대로 씁니다.

━━ [PV-115] 스팟 상세 이미지 출처 ━━

· 상세 이미지의 출처 표기를 다시 노출합니다.
  출처가 없는 스팟에는 표기가 나오지 않습니다.

━━ [PV-114] 지도 바텀시트 ━━

· 지도 하단 시트에 뜨는 숫자를 북마크 수에서 추천 수로 바꿨습니다.

━━ [PV-59] 무드 필터 임시 처리 제거 ━━

· 신규 무드(햇살·야경)를 앱에서 임시로 처리하던 계층을 걷어내고
  서버 응답을 그대로 쓰도록 바꿨습니다.

━━ 그 밖에 ━━

· 지도 하단 스팟 시트의 핸들을 제거했습니다.
· edgeToEdge 대응했습니다.

━━ 알려진 사항 ━━

· 개발 서버 빌드라 운영 앱과 데이터가 다릅니다.
· [확인됨] 무드를 두 개 이상 고르면 한 개만 적용됩니다. 서버가 아직
  다중 무드를 지원하지 않아 생기는 현상이며, 앱에서 임시로 메워주던
  처리를 이번에 걷어내면서 드러났습니다. 따로 보고하지 않으셔도 됩니다.
· [확인됨] 개발 서버에 야경 스팟 데이터가 0건이라 야경만 고르면
  결과가 비어 있습니다. 앱 문제가 아닙니다.
· 개발자 메뉴(Dev Mode: 환경 배지 탭 → 패스코드 1123)
