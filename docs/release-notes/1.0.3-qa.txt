Pickflow 1.0.3 (1000301) · QA 빌드 · 개발 서버

━━ 설치 전 반드시 읽어주세요 ━━

1. 기존 Pickflow 앱을 삭제한 뒤 설치해주세요.
   이 빌드는 직전 QA 빌드(1.1.0)보다 버전이 낮아 덮어쓰기 설치가 막힙니다.

2. 설치 후 카카오 로그인을 다시 해주세요.
   삭제 설치라 로그인 정보가 초기화됩니다.

━━ 이번에 고친 것 ━━

[신고]
· 로그인하지 않은 상태에서도 스팟 신고가 가능하던 문제를 수정했습니다.
  이제 로그인 안내 팝업이 뜹니다.
· 내가 등록한 스팟에는 "잘못된 정보가 있나요?" 버튼이 더 이상 보이지 않습니다.

[북마크]
· 북마크 버튼을 빠르게 여러 번 누르면 "북마크 변경에 실패했어요."가
  뜨던 문제를 수정했습니다.
· 탐색 목록과 지도 바텀시트에서 이미 저장한 스팟이 저장 안 된 것처럼
  보이던 문제를 수정했습니다. 화면을 나갔다 와도 상태가 유지됩니다.
· 북마크 아이콘을 하트에서 책갈피 모양으로 변경했습니다.

[화면]
· 공지사항 목록과 상세에서 하단이 잘려 보이던 문제를 수정했습니다.
· 탐색 목록이 2페이지 이후로 더 불러오지 않던 문제를 수정했습니다.

━━ 중점 확인 부탁드립니다 ━━

1. [중요] 휴대폰을 3버튼 내비게이션으로 바꾼 뒤 공지사항 목록과 상세의
   맨 아래가 가리지 않는지 확인해주세요. 제스처 내비게이션에서는
   재현되지 않아 이 설정에서만 검증이 가능합니다.
2. 탐색 목록을 3페이지 넘게 계속 스크롤해주세요.
3. 북마크 버튼을 5번 연속으로 눌러보고, 실패 안내가 뜨지 않는지와
   최종 상태가 누른 횟수와 맞는지 확인해주세요.
4. 로그아웃 상태에서 다른 사람 스팟의 신고 진입을 시도해주세요.

━━ 알려진 사항 ━━

· 개발 서버 빌드라 운영 앱과 데이터가 다릅니다.
